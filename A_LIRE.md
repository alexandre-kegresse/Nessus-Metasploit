# À lire en premier

Ce dossier est le projet du runtrack **Nessus / Metasploit** (soutenance 30/10).

## Comment on travaille

- **GitHub = la référence** (persistant). Ce dossier dans Documents sert à **poser tes
  captures** et à relire les fichiers.
- Quand tu fais une manip : **capture d'écran** → tu la ranges dans
  `captures/jobXX-.../` (le bon job).
- Quand tu veux que je mette à jour le README et que je pousse sur GitHub : tu me le dis,
  je récupère tes captures, je les annote et je pousse.

## Par où commencer

1. Lis `docs/00-guide-lab.md` : c'est le mode d'emploi des manips, job par job.
2. Fais les Jobs 02 et 03 (créer les 2 VM). Note les **IP** dans le README.
3. Préviens-moi quand tu as des captures : on avance ensemble.

## Fichiers

- `README.md` → le dossier de rendu (se remplit au fur et à mesure).
- `docs/00-guide-lab.md` → mon guide pratique (pas pour le jury).
- `docs/01-nessus-presentation.md` → Job 01, la doc Nessus (va dans la présentation).
- `captures/` → mes captures, triées par job.
